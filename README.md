# Codex + ZCode 用量桌面悬浮窗

置顶圆角深色卡片，实时显示 Codex CLI 和 ZCode 的额度用量。数据全部来自本地文件，纯读取、不联网。

## 显示内容

- **时钟**：本地时间 HH:MM:SS，每秒跳动（按墙钟对齐，不会越走越慢）
- **CODEX 组**
  - 5 小时窗口：剩余百分比 + 进度条 + 距重置倒计时
  - 本周额度：剩余百分比 + 进度条 + 距重置天数
- **ZCODE 组**
  - 今日额度：剩余百分比 + 进度条 + 剩余绝对值（如 78.8M）+ 距当日重置倒计时
- **页脚**：最新会话上下文占用 + Codex 数据新鲜度

剩余视角，与官方界面的数字口径一致。颜色分级（按剩余）：≥40% 绿色，20%–40% 黄色，<20% 红色。

## 数据来源

- Codex：`~/.codex/sessions/**/*.jsonl` 里官方回写的 `rate_limits` 快照
- ZCode：`~/.zcode/v2/logs/YYYY-MM-DD.log` 里的 `payload.data.balances` 额度快照（当日 token 池，自然日重置）

两者都是工具运行时自动写入的最新快照，悬浮窗每 30 秒读取一次。

## 使用

**开启**：双击 `启动悬浮窗.bat`（或直接双击 `codex_usage_widget.pyw`）。

**关闭**：点右上角小圆圈 ✕（鼠标移上去会展开成"✕ 关闭"），或右键 → 退出。

**三个功能按钮**（右上角 ◆ — ✕）：平时都是小符号，鼠标悬停任一个会展开成胶囊显示完整功能文字（"固定位置/解除固定"、"最小化"、"关闭"），同时相邻按钮自动让位隐藏，移开后恢复。

**固定位置**：点右上角 ◇（空心=可拖动）→ 变成实心蓝色 ◆，位置锁定不可拖动，再点解锁。状态重启保持，右键菜单也可切换。

**背景透明**：右键 → "背景：切换为透明"，文字和进度条直接悬浮在壁纸上（仅保留细描边），再切回实心深色。状态重启保持，两种形态都支持。浅色壁纸建议用实心模式保证可读性。

**最小化**：点右上角"—"圆圈 → 收缩成屏幕顶部迷你条（时钟 + Codex 5h/周剩余 + ZCode 今日剩余 + 余额），点迷你条任意处弹回完整卡片。两种形态位置分别记忆。

- **移动**：按住窗口任意处拖动，位置自动记住，下次启动还在原处
- **刷新**：右键 → 立即刷新（平时每 30 秒自动刷新，迷你条形态也刷新）

## 开机自启（可选）

按 `Win+R` 输入 `shell:startup` 回车，把 `启动悬浮窗.bat` 的快捷方式放进去。

## 依赖

Windows + Python 3（本机路径 `D:\Python314`），无第三方库。
