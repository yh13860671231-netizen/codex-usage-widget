# AI Coding Radar

## AI 编程资源驾驶舱

AI Coding Radar 是一个 Windows 本地桌面工具，用于统一管理和查看多个 AI 编程平台、多账号资源状态。

当前项目由原始 Codex + Zcode 用量悬浮窗演进而来。

## 项目目标

帮助开发者快速判断：

- 当前哪个 AI 平台最适合使用
- 哪个账号额度更充足
- 额度何时恢复
- 如何合理分配高级模型资源

## V1.0 支持平台

- 火山引擎 Coding Plan
- Zcode
- Codex（多账号）

## 核心功能

- 5小时额度
- 7天额度
- 月额度
- 恢复倒计时
- 多账号管理
- Windows 托盘提醒
- 本地安全存储

## 技术方向

- Python
- PySide6
- SQLite
- Provider 插件架构

## 开发原则

稳定优先。

先完成可实际使用版本，再扩展 AI 自动调度、多模型路由等高级能力。
