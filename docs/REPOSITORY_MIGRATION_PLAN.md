# AI Coding Radar 仓库迁移计划

## 当前仓库名称

codex-usage-widget

## 目标仓库名称

ai-coding-radar

## 说明

当前项目已经从单纯的 Codex 额度小组件扩展为统一 AI 编程资源驾驶舱。

未来支持：

- 火山引擎 Coding Plan
- Zcode
- Codex 多账号
- 其他 AI Coding 平台

因此仓库名称应体现整体定位，而不是限定 Codex。

## 执行要求

由于当前自动化开发工具可能具备 GitHub 仓库管理权限不同，仓库改名不作为代码功能的一部分。

由具备仓库管理权限的工具或开发者执行：

1. 将仓库名修改为 ai-coding-radar
2. 保留 Git 历史
3. 确认旧地址跳转正常
4. 更新 README、文档中的仓库引用

## Zcode/Codex注意事项

开发过程中如发现仓库仍为旧名称，不应创建新仓库。

优先完成仓库改名，再继续开发。

改名不会影响项目设计和代码结构。
