# AI Coding Radar Development Rules

## 1. 总原则

本项目采用工程化开发方式。

原则：

- 文档先行
- 小步提交
- 可测试
- 可回滚

---

# 2. 架构规则

必须保持：

UI层
 ↓
Service层
 ↓
Provider层
 ↓
数据层

禁止：

UI直接访问数据库。

---

# 3. Provider规则

所有AI平台必须独立封装。

统一接口：

- 获取账号
- 获取额度
- 获取刷新时间
- 获取状态

新增平台不能修改核心业务。

---

# 4. 数据安全规则

必须：

- 本地存储
- 敏感信息加密
- 最小权限

禁止：

- 上传账号信息
- 上传项目文件
- 记录敏感日志

---

# 5. 测试规则

每个功能必须提供：

- 正常测试
- 异常测试
- 边界测试

提交代码前必须自测。

---

# 6. 审核流程

流程：

开发
 ↓
Git提交
 ↓
代码审核
 ↓
测试验收
 ↓
合并发布

---

# 7. 版本规则

V1.0目标：

快速可用。

新增需求进入候选列表，不随意加入当前版本。
