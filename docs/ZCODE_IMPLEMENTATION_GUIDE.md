# Zcode Implementation Guide

## AI Coding Radar V1.0

本文件用于指导 Zcode/Codex 等开发 Agent 执行项目开发。

---

# 1. 开发目标

目标：快速完成可实际使用的 Windows AI 编程额度管理工具。

核心原则：

- 先可用，再扩展
- 稳定优先
- 本地优先
- 模块化设计

---

# 2. 开发顺序

## Phase 1 基础框架

完成：

- 项目初始化
- PySide6 UI框架
- SQLite数据库
- 配置管理
- 日志系统

禁止：

- 提前开发复杂自动化
- 接入大量平台

---

## Phase 2 核心功能

完成：

- 平台卡片
- 额度周期显示
- 倒计时
- 状态计算

---

## Phase 3 Provider接入

采用插件架构。

每个平台独立 Provider：

- volcano
- zcode
- codex

不得将平台逻辑写死在主程序。

---

## Phase 4 多账号

重点测试 Codex 多账号隔离。

要求：

- 数据独立
- 状态独立
- 推荐独立

---

# 3. 提交规范

每次提交必须包含：

1. 修改内容
2. 测试结果
3. 已知问题
4. 下一步计划

禁止大范围无说明提交。

---

# 4. 开发禁止事项

V1禁止：

- 上传用户数据
- 自动修改账号
- 自动执行AI任务
- 云端同步
- 保存明文敏感信息

---

# 5. 代码要求

要求：

- 模块化
- 可测试
- 有注释
- 有异常处理
- 有日志

---

# 6. 完成标准

开发完成后必须通过：

- 功能测试
- 安全检查
- 稳定性测试
- 打包测试
